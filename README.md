# 🔐 APKI Secure - موبائل سرور

آپ کا محفوظ، تیز، اور مکمل کنٹرول والا موبائل سرور۔

## ✨ خصوصیات
- 🔑 مکمل ہارڈویئر باؤنڈنگ
- 🔐 LICENSE + .env انٹیگریشن
- 📱 موبائل آپٹمائزڈ
- 🤖 ماڈیولر ماڈلز (DeepSeek, Gemini, ChatGPT-4o, Qwen-2.5)
- 🌐 گٹ ہب پیجز سپورٹ
- 🚀 بغیر ٹرمینل کے استعمال

##  استعمال

### ویب سے:
1. `index.html` کو براؤزر میں کھولیں
2. سسٹم خودکار چیک ہو جائے گا
3. چیٹ بوٹ یا دیگر فیچرز استعمال کریں

### پائتھن سرور:
```bash
python3 apki_secure.py
```
پھر `http://localhost:8000` کھولیں

## 📁 فائلز
- `index.html` - مین انٹرفیس
- `apki_secure.py` - پائتھن سرور
- `.env` - کنفیگریشن (GitHub پر نہ ڈالیں)
- `LICENSE` - ہارڈویئر لائسنس

## 🔒 سیکیورٹی
- `.env` فائل کو کبھی GitHub پر اپلوڈ نہ کریں
- API Key محفوظ رکھیں
- صرف اپنے موبائل/سرور پر استعمال کریں
